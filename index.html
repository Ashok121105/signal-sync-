📋 Project Information

SIGNAL SYNC is a software-only prototype for motion, impact, GPS monitoring and alert management.

Current prototype uses simulated sensor inputs, browser GPS, browser notifications, virtual LED/buzzer/OLED, localStorage history and an explainable AI-style classification layer. Physical MPU6050/ESP32/GPS hardware can be integrated in a future version.
